# LalaCoffee — Website bán cà phê và nước giải khát

Đồ án học phần Chuyên đề ASP.NET sử dụng C#, ASP.NET MVC 5, .NET Framework 4.8,
Entity Framework 6 và SQL Server.

Repository được tổ chức để bổ sung mã nguồn theo từng nhóm chức năng.
Tài liệu cài đặt và hướng dẫn sử dụng đầy đủ được bổ sung trong đợt hoàn thiện.

> Lịch sử commit của bộ chia này thể hiện các **đợt nhập mã nguồn từ một dự án đã hoàn thành**,
> không phải ngày viết ra các chức năng lần đầu.

## Cấu trúc mã nguồn

Toàn bộ solution ASP.NET MVC 5, source C# và script database nằm trong `src/`.
Các thư mục `progress-report/`, `thesis/` và `setup/` nằm tại gốc repository.
